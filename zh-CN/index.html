《牛气碰碰》用户隐私保护指引

适用版本：SUD OpenPaaS 版
更新日期：2026年11月2日 · 生效日期：2026年11月2日

本指引由《牛气碰碰》（英文名 Moo Smash）的个人开发者及运营者游明珠（以下简称“我们”）制定，说明我们在提供游戏及处理用户咨询时如何处理信息。联系邮箱：371652098@qq.com。

本指引适用于通过 SUD OpenPaaS 分发、在宿主应用中运行的游戏版本，不替代宿主应用、平台或其他发行版本各自适用的隐私政策。

一、开发者处理的信息

我们仅在实现具体功能所必要的范围内处理信息，当前游戏版本涉及以下内容：

  • 本地游戏数据：关卡解锁和完成记录、挑战积分及游玩统计、道具和皮肤状态、引导完成标记、音效及其他游戏设置。游戏在当前设备的宿主应用本地存储空间中读写这些数据，用于保存进度、显示成绩、恢复设置及提供相应玩法。
  • 界面适配信息：宿主提供的语言设置、窗口或屏幕尺寸、设备像素比、安全区域、状态栏及菜单位置。游戏读取这些信息，用于选择显示语言、适配画面和避免界面遮挡。
  • 操作事件：游戏在运行时处理点击、拖动及前后台状态，以响应操作、暂停或恢复游戏和进入省电模式。我们没有通过游戏接入独立的用户行为分析或屏幕录制服务。
  • 你主动发送的咨询信息：当你通过邮箱联系我们时，我们会处理你的发件邮箱、邮件内容以及你自愿提供的截图或问题说明，用于回复、排查问题及处理隐私请求。请不要发送与问题无关的身份证件、密码等敏感信息。

当前 OpenPaaS 版不设置开发者自建账号注册或云存档，不主动调用平台用户资料接口获取你的昵称、头像、性别、地区、手机号、身份证号或好友关系，也不提供好友排行榜及好友超越通知。我们不通过游戏申请通讯录、精确位置、相机或麦克风权限；游戏祝福及夸奖语音为预录音频，不需要录制你的声音。宿主应用自身的登录、实名认证或权限处理由其另行说明。

二、第三方插件、SDK及平台服务

1. SUD OpenPaaS 运行平台与宿主应用

本游戏依赖宿主应用集成的 SUD OpenPaaS 运行环境，提供游戏加载、资源缓存、本地存储、界面和生命周期等基础能力。SUD 官方隐私政策将其服务提供方列为 SUD Global Inc. 及其关联公司；具体宿主应用及其服务主体，请以你使用的应用所披露的信息为准。

游戏直接读取的平台信息及用途已在第一节列明。平台和宿主应用可能为提供自身服务处理账号、设备、网络或运行日志等信息；其具体处理类别、用途、保存地点、权限及权利行使方式，以实际服务及其隐私说明为准。可查阅 SUD 官方隐私政策，以及宿主应用内的隐私政策。我们不将平台自行处理的信息全部视为本游戏开发者已经收集的信息。

2. 广告及其他插件

本指引所对应版本尚未配置开发者侧 OpenPaaS 广告位，不主动请求横幅或激励视频广告，也没有额外集成独立的广告、统计或社交插件。若后续启用广告或新增涉及个人信息的服务，我们会在启用前更新相关信息、用途和第三方说明，并在依法需要时取得相应同意。宿主应用自行提供的广告或服务，适用其自身说明。

3. 本隐私网页的托管

本页面使用 GitHub Pages 托管。访问页面时，GitHub 可能处理 IP 地址、浏览器或设备信息、请求时间等访问日志，具体规则见 GitHub 隐私声明。本页面没有嵌入广告、访问统计脚本或跟踪像素，也不会读取你的游戏存档。

三、信息的存储与保存期限

关卡、积分和设置等游戏数据主要保存在你当前设备的宿主应用本地存储空间，我们未为该版本建立开发者云存档服务器。清除游戏或宿主应用数据、卸载应用、更换设备等操作，可能导致本地进度丢失，无法由我们从云端恢复。平台缓存保留行为可能因宿主而不同。

你主动发送的联系邮件保存在用于处理咨询的邮箱及必要的处理记录中。除法律法规另有规定外，我们仅在完成咨询、排查问题、处理权利请求或相关争议所必要的最短时间内保存这些信息，目的完成后删除或匿名化。

平台、宿主应用、邮件服务及 GitHub 自行处理的信息，其保存期限、地点及跨境处理按各自适用的规则执行。我们不会以“本地存档”来承诺这些独立服务的全部数据均留在你的设备或某一国家、地区。若我们新增需要跨境提供个人信息的处理活动，将依法履行告知、同意及其他相应要求。

四、信息的使用、对外提供与安全

我们在本指引说明的用途和必要范围内使用信息，不出售你的个人信息，不利用本地游戏进度建立开发者广告画像。除本指引说明的服务、你的明确请求、依法取得的授权或法律法规要求外，我们不会主动向第三方共享、转让或公开披露你的个人信息。

确需新增共享、转让或公开披露时，我们会依法说明接收方、目的、方式及信息类型，并在法律要求时取得单独同意。超出原有目的或合理范围使用信息前，我们会另行告知并履行所需的同意程序，不把继续游玩一概视为对新增处理的同意。

我们采取与实际处理规模相适应的访问控制及其他合理保护措施，仅由处理问题所必要的人员接触咨询信息。发生信息安全事件时，我们会采取补救措施，并依法履行通知及报告义务。

五、你的权利及授权管理

你可以通过 371652098@qq.com 联系我们，就我们实际处理的个人信息申请查阅、复制、更正、删除、撤回同意，或行使适用法律规定的其他权利。我们会核实处理请求所必要的信息，并在适用法律规定的期限内回复；如无法满足请求，会说明原因。

本地存档可以通过宿主应用提供的游戏数据或缓存管理功能处理，具体入口及能否仅清除本游戏数据取决于宿主。清除本地存档可能同时删除关卡、积分和皮肤记录，请谨慎操作。我们目前没有能够远程找回或单独删除你设备存档的开发者服务器。

对宿主或平台授予的权限，可在相应应用的设置、隐私或权限管理入口中调整；入口名称因平台不同而不同。你也可以停止使用游戏。撤回同意不影响撤回前基于有效同意开展的处理，但可能使依赖相应权限的功能无法使用。关于宿主或平台账号及其独立处理的数据，请联系对应服务提供方。

六、未成年人个人信息保护

未成年人应在监护人的指导下阅读本指引，并遵守宿主平台的适龄及使用要求。对于不满十四周岁的儿童或其他依法需要监护人同意的情形，我们将在法律要求的范围内取得监护人同意并提供相应保护。若监护人认为我们不当处理了儿童信息，可通过上述邮箱联系我们；核实后，我们会依法删除、停止处理或采取其他适当措施。请勿在咨询邮件中提供与解决问题无关的儿童身份信息。

七、指引更新与联系我们

我们会随游戏实际功能及处理活动的变化更新本指引，并在页面注明更新日期。对于处理目的、信息范围或权利等重大变化，我们会在生效前通过游戏提示、平台公告或其他适当方式告知，并在依法需要时重新取得同意。
